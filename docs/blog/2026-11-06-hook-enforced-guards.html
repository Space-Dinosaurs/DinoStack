Hook-enforced guards: rules the harness applies, not rules the agent remembers

2026-11-06

A rule an agent has to remember is a rule it can forget, or argue itself out of. DinoStack's Skeptic round cap shows what that costs. Before a hook enforced it, the cap was enforced only by "the conductor tracks re-route count in-context", and a single session ran 12 Skeptic rounds and 13 spawns on one unit with no mechanism firing. DinoStack's answer is to move rules that can be checked mechanically into Claude Code lifecycle hooks, which the harness runs on every matching event whether or not the agent remembers the rule. This post covers three of them.

The abdication guard

DinoStack expects the conductor to proceed with an obvious, non-destructive next step rather than end its turn asking permission. hooks/enforce-no-abdication.py is a Stop hook, scoped to the main session so it governs the conductor and not its Workers, that reads the final message and blocks the stop on any of three shapes:

  • a permission-seeking question about a next step;
  • an announced default, such as "proceeding with X unless you say otherwise", followed by no action at all in that turn. This one fires only on positive proof of a stall: the hook must read the transcript, find the start of the current turn, and see zero tool calls since then;
  • an ## Operator decisions block that offers two or more items without a recommendation, a co-equal ballot written as prose.

The block does not simply say "proceed". The hook cannot tell a derivable default wearing permission-seeking language from a genuine hard stop, so its directive offers two exits: proceed now, in the same turn, if the step is non-destructive and a default is derivable; or, if a real stop condition holds, such as an irreversible action, information only you have, or an operator-only grant, say so explicitly and wait. Detection is deliberately biased toward missing a case rather than firing falsely, and a counter caps consecutive blocks at 2 per user message so it cannot loop.

This guard is opt-in. It runs only when abdication_guard_enabled is explicitly true in .agentic/config.json; the shipped config template and /ds-init-project set it, so a scaffolded project is covered and a project without the file is not. AE_ABDICATION_GUARD_DISABLE=1 turns it off.

The turn-shape guard

The first pillar of DinoStack's vision is to guard operator attention: surface decisions and work-stoppages, not status. A conductor turn is warranted only when it carries one of four warrants: an answer to your message, an operator decision, a stoppage (a Waiting: line), or a completion. Everything else, such as an agent spawned, an agent returned or CI going green, is a silent continue with no turn written. hooks/enforce-turn-shape.py checks the final message against that contract, with three checks in different postures:

  • Zero-warrant turns block, but only when the turn is unprompted. The check never fires on the first turn after a genuine operator message, or on answer-shaped prose.
  • Execution turns block when they carry prose. A turn that makes a decision, stops or completes, without answering you, must be a short structured block: an identity line, up to three status lines, then any ## Operator decisions, and nothing else.
  • Decision-item sprawl is advisory and only logged.

Some rules are deliberately left out. Answer relevance and editorial addenda stay as prose enforced by review, because every candidate mechanization reduces to a growing phrase blocklist or to a semantic judgment the project's own design principles rule out. Unlike the abdication guard, this one is on by default: it runs unless turn_shape_guard_enabled is false, and a missing config file counts as on. AE_TURN_SHAPE_GUARD_DISABLE=1 turns it off.

The Skeptic round cap

hooks/enforce-skeptic-round-cap.py runs before every Skeptic spawn and allows 3 rounds per unit. It keys the count on the stable unit key that must lead the "Diff under review" line of every Skeptic brief, not on the conductor's git branch: the conductor stays on main while engineers work in worktrees, so a branch key would let one unit's rounds exhaust another's budget. A brief whose "Diff under review" line carries no valid key is denied.

Past the cap, only you can reopen it. A plain reply such as "grant" lifts the cap for the rest of the session, up to 6 rounds per unit; past that, each grant allows exactly one more round, and the skeptic-grant- token the denial prints works for that unit and round. Nothing the conductor writes to the hook's state file reopens it. There is no config toggle and no kill switch.

Fail open, and log every fire

Every DinoStack hook fails open: a parse error, a missing file or an unexpected payload exits without denying anything, because an enforcement gap is preferable to a blanket block. The round cap has the one deliberate exception: it denies a round allowed by an operator grant when it cannot record it, since allowing it would let one grant re-allow every retry. Every enforce-*.py hook also appends a line to .agentic/.enforcement-fires.jsonl, and the abdication guard logs every verdict, plain allows included, so its allow-to-deny ratio can be measured rather than guessed. Logging is strictly observation and never changes a verdict.

Why it matters

The record behind these hooks is the argument for them. The round cap existed as prose while one unit ran 12 rounds, and advisory enforcement of the execution-turn shape shipped three times without the prose going away before the check was made blocking. Hooks run on every turn and every spawn regardless. The guards here are also honest about their limits: they fail open, say which cases they cannot see, and leave judgment calls to review rather than pretending a phrase match can make them.

One scope note: these are Claude Code lifecycle hooks. Other adapters carry their own hand-authored hook files, so check the adapter you use before assuming a guard is live there.
