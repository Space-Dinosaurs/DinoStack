Notes from the DinoStack project.

  • 2026-11-06 One methodology, eleven harnesses: DinoStack's adapters

    One content source packaged for 11 AI coding tools, with Claude Code updated first and on-demand catch-up PRs for the other ten.

  • 2026-11-06 Outcome rubrics and qa_criteria: defining done before the work starts

    Verification commands, an operator-confirmed outcome rubric the Skeptic grades, and a qa_criteria test plan, all written before the engineer starts.

  • 2026-11-06 Capability preflight: checking an agent's tools before it starts

    Before every spawn, the conductor checks the tools the agent declares for this task, installs the safe ones, and by default refuses the spawn when a required tool is missing.

  • 2026-11-06 Hook-enforced guards: rules the harness applies, not rules the agent remembers

    The abdication guard, the turn-shape guard and the Skeptic round cap run as Claude Code hooks, so the harness applies them on every matching event: the round cap on every Skeptic spawn, the turn-shape guard on every conductor turn by default, and the abdication guard once a project opts in.

  • 2026-11-06 Worktree-isolated engineers: why the conductor never edits shippable files

    Every shippable change, even a one-line fix, goes to an engineer in its own git worktree branched from origin, so each PR holds one engineer's work and nothing else.

  • 2026-11-06 Risk classification: Trivial, Low and Elevated

    Every task is classified before it starts, and the class decides which agents spawn, whether a Skeptic reviews the work, and whether QA runs.

  • 2026-11-06 The Skeptic: DinoStack's adversarial review loop

    A fresh reviewer with no shared context, findings rated Critical, Major or Minor, a hard round cap, and briefs that may not prime the reviewer.

  • 2026-11-06 From session friction to tracker tickets: DinoStack's feedback capture

    At wrap time, agents turn the friction they hit into draft reports, and a human triages them into tickets in your own tracker.

  • 2026-11-06 One conversation, many tickets: DinoStack's conductor and lanes

    You talk to one conductor while several tickets run in parallel, each through a ticket workflow scaled to its risk.
